# WDD 131: Dynamic Web Fundamentals

This repository contains my coursework and practice work for WDD 131, a course focused on building dynamic and responsive web experiences using HTML, CSS, and JavaScript.

## Course Overview

WDD 131 introduces students to the fundamentals of modern web development. The course emphasizes:

- Semantic HTML structure
- CSS styling and layout techniques
- Responsive design and accessibility
- JavaScript interactivity
- Using web development tools and best practices

## Purpose of This Repository

This project serves as a student portfolio and learning workspace for the course. It includes:

- A personal home page and profile landing page
- Styling and layout files for the website
- JavaScript enhancements for dynamic page behavior
- Weekly course materials and assignments

## Repository Structure

- `index.html` — main course/home page
- `styles/` — CSS files for layout and design
- `scripts/` — JavaScript files for page behavior
- `images/` — profile and media assets
- `week01/` and `week02/` — weekly assignments and exercises

## Learning Goals

By the end of the course, students should be able to:

- Create well-structured and accessible web pages
- Apply modern CSS for layout, spacing, and visual design
- Add simple interactivity with JavaScript
- Build a polished personal or class project using core web technologies

## About the Project

This repository reflects the work completed in WDD 131 and demonstrates the growth of a beginner web developer as they learn to design, code, and style functional web pages.
